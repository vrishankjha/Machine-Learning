# Machine-Learning

Used Car Price Prediction (Cars24 Dataset)

Objective: Built a regression model to predict used car prices using features like year,fuel type,and kilometers driven.

Results: Achieved model accuracy between 83% to 93%, with XGBoost and Random Forest performing best.

Flight Price Prediction

Objective: Predicted flight ticket prices based on travel route, time, and airline.

Results: Achieved 99%+ accuracy across all models after applying correlation analysis and removing redundant features.

FASTag Fraud Detection

Objective: Classified FASTag transactions as fraudulent or genuine based on behavioral patterns.

Results: Achieved 93% to 100% accuracy, helping detect fraudulent activity with high precision.

Transaction Fraud Classification

Objective: Worked on a 50,000-row labeled dataset to detect financial fraud using classification models.

Results: Achieved 80% to 100% accuracy across different models using confusion matrix for evaluation.
